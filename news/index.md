# Changelog

## svines 0.3.0

- Support for modeling data with discrete variables.

- Add compatibility with rvinecopulib 1.0.0 while retaining support for
  rvinecopulib 0.7.x.

## svines 0.2.7

CRAN release: 2025-06-12

- Make unit tests safer for dependencies.

## svines 0.2.4

CRAN release: 2025-01-15

- Adapt to new rvinecopulib version.

## svines 0.2.0

CRAN release: 2023-11-21

- Add new functions to compute pseudo-residuals.

- Add `nobs` to [`logLik()`](https://rdrr.io/r/stats/logLik.html)
  output, so that [`BIC()`](https://rdrr.io/r/stats/AIC.html) can be
  called on models.

## svines 0.1.2

- Fix potential integer overflow in internal seeds.

## svines 0.1.1

CRAN release: 2022-03-23

- Initial version.
